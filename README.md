# Undergraduate Engineering Projects

This repository collects selected coursework, simulations, and design projects completed during the B.Tech. Automation and Robotics Engineering program at Amrita Vishwa Vidyapeetham.

The contents reflect foundational work across mechanical design, programming, control systems, and simulation, and are preserved as part of the academic portfolio.

---

## Included Areas

### Control Systems Simulations
MATLAB scripts exploring transfer functions, stability analysis, and spring–mass system modeling.

### Finite Element Analysis Studies
ANSYS simulations investigating stress distribution and structural behavior in mechanical components.

### Programming Projects
Procedural programming exercises including a C-based travel planner application.

### Data Science and Machine Learning Exercises
Introductory notebooks covering data analysis and machine learning fundamentals.

### Design and Manufacturing Projects
Early design-focused projects such as product prototyping and concept development.

---

## Purpose of this Repository

This repository is intended to document academic coursework and foundational engineering exercises.

More advanced robotics research and system development work is available in other repositories.
